# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Everyone participating in issues, pull requests, reviews, discussions, and other
project spaces is expected to follow it.

## Reporting

Report unacceptable behavior privately to the repository maintainers through
the contact method published on the owning GitHub organization profile. Reports
will be handled promptly, fairly, and with respect for the reporter's privacy.
