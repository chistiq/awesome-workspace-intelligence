# Security Policy

This repository is a curated list, but links and validation automation can
still create security risk.

## Report privately

Use GitHub's private vulnerability reporting for:

- a vulnerability in repository automation;
- a link that now distributes malware or captures credentials;
- a supply-chain concern that should not be disclosed before mitigation.

If private reporting is unavailable, contact the maintainers through the owning
GitHub organization profile. Do not include secrets or exploit details in a
public issue.

## Report publicly

Use the **Report a problem** issue form for ordinary dead links, redirects,
incorrect descriptions, moved projects, or maintenance-status corrections.
